# API 设计约定（测试用）

## REST

- 资源路径用名词复数或约定好的单数集合名；动词放在 HTTP 方法上。
- 成功响应 JSON 结构稳定；错误返回 `{ "error": "..." }` 与合适 HTTP 状态码。

## 兼容

- 新增字段默认可选；删改字段需版本说明或迁移期。
- 列表接口考虑分页或上限，避免一次拉全表。

## Web 操作台专用

- `/api/*` 与静态 SPA 分离；非 API 路径 fallback 到 `index.html`。
- 配置类数据持久化在 `.dev-workflow/web-ui/`，便于本地调试。

## 文档

- 对外接口在 README 或 OpenAPI 片段中留最小示例。
