# 技术方案规范（项目占位）

> 本文件由 `ai-rules.yaml` 挂到 `design_tech_solution` / `implement_code`，注入对应 prompt 的 `{{ai_rules}}`。

## 底线要求

1. 写代码前必须先出技术方案；方案未由用户确认不进入实现。
2. 定位是给用户做全局把控的短文档：**核心是 DDL 与领域命名**，实现只讲方向。
3. 正文（不含 DDL）150 行以内；不写文件清单、方法级细节。
4. 领域名词必须先定义再用，中英文命名一一对应。

## 必含章节

背景与目标 / 领域模型与术语（术语清单 + classDiagram）/ 数据结构及说明（完整 DDL + 字段表）/ 实现方向 / 关键接口 / 兼容性与风险 / 人工后续事项。
